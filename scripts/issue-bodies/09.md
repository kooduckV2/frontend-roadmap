## 目标
理解 Node.js 运行时。**这周不许跳过去直接上 NestJS**，框架会掩盖你对运行时的无知。

## 阅读
《深入浅出Node.js》：模块机制 / 异步 I/O / 异步编程 / 内存控制 / 构建 Web 应用

## 动手
- [ ] 纯 Node 写一个 HTTP 服务（不用框架）：路由、静态文件、JSON 解析
- [ ] 手写一个中间件（洋葱模型雏形）
- [ ] 写一个 Stream 管道（读文件 → 转换 → 写文件）

## 验收
- [ ] 能解释事件循环 6 个阶段，`poll` 卡住会发生什么
- [ ] 讲清 CJS 与 ESM 的加载差异（同步/异步、值拷贝/活绑定）
- [ ] 讲清 Stream 的背压（backpressure）机制
- [ ] 能解释 `Buffer` 与内存分配，以及为什么会内存泄漏
