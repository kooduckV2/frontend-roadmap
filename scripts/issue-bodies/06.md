## 目标
从「写页面」升级到「造组件」，建立组件复用能力。

## 阅读
《剑指Vue3——从入门到实践》第 5–8 章（组件 / 插槽 / provide-inject / 生命周期）

## 动手
- [ ] 抽出 5 个可复用组件：数据表格、表单、弹窗、分页、文件上传（都带 TS 类型）
- [ ] 抽出 3 个 composable：分页、表单校验、请求 loading

## 验收
- [ ] 讲清 props 单向数据流，子组件想改父数据该怎么办

- [ ] 讲清 `Teleport` 解决什么问题、`KeepAlive` 的 `include` / `max` 怎么用
- [ ] 组件有 README，props 有类型和默认值
