## 目标
性能、可观测性、收尾 —— 把它做成能写进简历的作品。

## 动手
- [ ] 前端：路由懒加载、`manualChunks` 分包、虚拟列表（1 万行运行历史 + 大日志）
- [ ] 后端：接口压测（autocannon）、加索引、连接池；对 Airflow 的调用做短缓存（同一运行详情 5 秒内不重复打）
- [ ] 可观测：健康检查（`@nestjs/terminus`，**必含"Airflow 可达"**）、结构化日志、慢查询日志
- [ ] v2 观测：k8s pod 状态（只读）、运行时间线、慢在哪一步
- [ ] 选做：Vue 渲染器 / 编译器（《Vue.js设计与实现》第 7–11、14–17 章）
- [ ] 选做：做成 PWA，手机上看运行状态

## 验收
- [ ] Lighthouse Performance ≥ 90，首屏 JS（gzip）< 200KB
- [ ] 运行列表接口 P95 < 200ms
- [ ] 1 万行表格滚动保持 60fps
- [ ] 能回答"上周那个任务为什么慢"，且全程没登服务器
- [ ] 仓库 README 有架构图，陌生人 10 分钟能跑起来
- [ ] 简历有 3 条成果，数字都是自己测过的
