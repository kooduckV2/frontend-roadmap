## 目标
**全栈打通 + 端到端类型共享** —— 这是整条路线最核心的一周。

## 阅读
《全栈Monorepo开发实战》第 1–3 章（pnpm workspace / 共享包）

## 动手
- [ ] `packages/shared` 定义 DTO：`CreateTicketDto`、`TicketStatus`、`ApiResponse<T>`
- [ ] 后端 controller 入参/出参直接引用 shared 类型
- [ ] 前端 `api/ticket.ts` 引用同一份类型
- [ ] axios 封装：泛型、拦截器、错误码、取消重复请求
- [ ] 联调：前端从 mock 切到真实 API

## 验收
- [ ] **故意改掉 shared 里一个字段名 → 前后端同时编译报错**（必须亲眼见到）
- [ ] 端到端跑通：登录 → 分页 → 新增 → 编辑 → 删除
- [ ] `pnpm -r typecheck` 一条命令检查全仓库
- [ ] 打 tag `v1.0-fullstack`，这是能拿出去演示的版本
